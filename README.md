# Subcontractor Evaluation Desktop App

A desktop scoring tool for evaluating drivers and suppliers against configured criteria, with spreadsheet-based input and output.

## Capabilities

- Separate evaluation flows for drivers and suppliers.
- Calculate scores from selected criteria.
- Read and update spreadsheet data.
- PyQt-based desktop interface.

## Stack

Python, PyQt5, Pandas, and OpenPyXL.

## Run locally

Install dependencies from `requirements.txt`, prepare the workbook expected by the application, then run `python main.py`.
